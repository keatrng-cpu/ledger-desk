# Watcher fills → Supabase (follow-up to #32)

| Piece | File |
| --- | --- |
| Endpoint | `src/routes/api/desk/fills.ts`: POST, `WATCHER_STATUS_TOKEN` bearer only (no CRON_SECRET fallback), owner from env `DESK_OWNER_USER_ID`, refuses shadow/dry-run (422); a payload the journal schemas refuse is 422 and writes nothing |
| Core | `src/lib/desk/watcher-fills.ts`: room_orders keyed `(user_id, client_order_id = signal)`, `phase = 'watcher'` (kept out of the room executor's audit list), ONE upsert statement with the forward-only rank check in its WHERE (placed → filled/rejected → closed); a replayed exit appends nothing. Validated through `journal/fill-schemas.ts` (stop-vs-entry, EXIT_REASON_IDS) before any write. An exit that arrives before its fill is stored on the order and the late fill records the trade opened+closed in one insert (never an open row). On `filled` it calls `recordRealFillFor` (desk_trades, underlier terms, opened once). On `exit` it calls `closeTradeFor`. It stamps `desk_card_journal.signal` |
| Journal | `src/lib/journal/server.ts`: the `recordRealFill` / `closeTrade` bodies are extracted into `recordRealFillFor` / `closeTradeFor(sql, userId, data, opts)`; the server fns call them. `opts.realizedPnl` (server-only, not in the client schemas) sets `pnl` to the real option-premium dollars, commission 0. Schemas moved to `fill-schemas.ts` |
| Migration | `migrations/0027_card_signal.sql`: additive `signal text` + partial index (not CONCURRENTLY: both migrators wrap each file in a transaction). **Not applied to prod by this PR**; `npm run build` runs `db:migrate` on deploy after merge |
| Watcher | `docs/watcher-fills-1016/watcher-fills.patch` (against the live tree after #32): `watcher/fills_sink.py` builds the payload from records the daemon already logged plus `state.position`, appends to `outbox.jsonl` (append-only, never blocks on the network, capped at 2 MB by refusing NEW rows, no-op when URL/token unset), and a background thread started at boot POSTs (5 s timeout, no lock held) and retries every 60 s; only the acknowledged (2xx/422) prefix is removed. Corrupt lines go to `outbox.jsonl.bad`. Skipped when `live` or `fire_enabled` is false, or when the record is shadow. Also carries the notify.py `format_event` try/finally fix. |
| Backfill | `scripts/backfill/fill-sig-85e8feddd99efe46.mts`: dry-run by default; `--apply --url` POSTs placed/filled/exit through the endpoint (idempotent). **Not applied.** |

Env: `DESK_OWNER_USER_ID` (Netlify) must be set or the endpoint returns 503. On the watcher, `WATCHER_STATUS_URL` + `WATCHER_STATUS_TOKEN` are already used for status; the fills URL is derived from it (or set `WATCHER_FILLS_URL`).
P&L: desk_trades entry/stop/exit stay in underlier (ES/MNQ) plan terms (so `r` is the plan R), but `pnl` is the REAL option P&L ((exit − fill) premium × qty × 100; 10/15 = −$36, not the ES-equivalent −$381.50), because pnl feeds computeLiveRiskState's daily/weekly halt and cron-stats live_net. The contract and premiums are also in room_orders and desk_trades.`why`.
