# ops/vps — ledger-gateway VPS ops services

Infra only. No trading rules change, no broker client anywhere. `ledger-gateway.service` is never restarted or modified;
its `.env` (0600) is read only by systemd via `EnvironmentFile=` and its venv is bind-mounted **read-only** into each unit.

| unit | what | caps |
|---|---|---|
| `ledger-watchdog.timer` → `.service` (60s) | box heartbeat / watcher / paper lanes / desk API / gateway tick lag & RTH 1m bar gaps / disk / memory | MemoryMax=64M, CPUQuota=50%, Nice=10 |
| `ledger-paper-trend.service` | backup copy of the box paper-trend lane (`paper/trend_paper.py` verbatim + `vps_trend.py` I/O shim), Restart=always | MemoryMax=200M, CPUQuota=50%, Nice=10 |
| `ledger-archive.timer` (Mon–Fri 17:15 ET) | GLBX.MDP3 ohlcv-1m ES/NQ/MNQ (get_cost must be $0 or abort) + live bars + desk card → `/var/lib/ledger-archive/YYYY/MM/DD/`; 60d NQ history cache in `hist/`; retention 3 GB | MemoryMax=200M, CPUQuota=50%, flock |
| `ledger-backtest.timer` (Mon–Fri 17:45 ET) | replays `trend_paper.step()` over the last 20 days of the cache → `/var/lib/ledger-backtest/latest.json` | MemoryMax=300M, CPUQuota=50%, flock |
| `ledger-charts.timer` (Mon–Fri 18:05 ET) | `charts_nightly.py` → `ops/charts` trade charts + JSON sidecars for the VPS paper lane (`/var/lib/ledger-paper/events.jsonl`) and the shadow learning report → `/var/lib/ledger-charts/`. Bars from the archive day files only (used only if the last archive.log `cost_usd` is 0); `PrivateNetwork=yes`, so no Databento/paid call is possible. Renders PNGs only if the venv has matplotlib, otherwise sidecars + report only | MemoryMax=300M, CPUQuota=50%, flock |

`ledger-paper-trend` is limited to 5 starts per 10 min (`StartLimitIntervalSec=600`, `StartLimitBurst=5`); after that it stays
failed and the watchdog raises `paper_vps_down`. Recover: `systemctl reset-failed ledger-paper-trend && systemctl start ledger-paper-trend`.
Archive/backtest timers are `Persistent=false`: a run missed while the VPS was down is skipped (re-run by hand with `systemctl start`).

Batch jobs share `/run/ledger-ops/batch.lock` (serial). journald `SystemMaxUse=200M`; logrotate for `/var/log/ledger-ops/*.log`.
Swap: 1 GB is added only if the host has none (this host already has a 2.3 GB swapfile).

**The archive's $0 depends on the guard, not on the plan alone.** Every call to `timeseries.get_range` goes through
`dbhist.pull()`, which (1) `guard()`s dataset/schema and (2) calls `metadata.get_cost` with the identical arguments and raises
before `get_range` unless the cost is exactly 0. Do not call `client.timeseries.get_range` anywhere else in this tree — a direct
call (or a new symbol/schema) bypasses the check and can bill. Today `get_cost` returns 0.0 for GLBX.MDP3 ohlcv-1m ES/NQ/MNQ.

Data guard: `dbhist.guard()` refuses anything except `GLBX.MDP3` / `ohlcv-1m`, and every pull calls `metadata.get_cost` first and
raises `CostAbort` (nothing downloaded) if the cost is > $0.

`paper/fastpath.py` memoises `trend_paper.rth()` (O(n²) inside `context()`); output is identical (tested) and the rule code is untouched.

## Least-privilege credentials
| unit | env file | DB role | can |
|---|---|---|---|
| ledger-paper-trend | `/etc/ledger-ops/paper.env` (DATABASE_URL only) | `ledger_ops_paper` | SELECT `live_market_bars_1m`; `default_transaction_read_only=on` |
| ledger-watchdog | `/etc/ledger-ops/watchdog.env` (DATABASE_URL, CARD_URL) | `ledger_ops_watchdog` | SELECT gateway tables + ops tables; INSERT/UPDATE `ops_alerts`, `ops_heartbeats` only |
| ledger-backtest | none | — | reads the local parquet cache only |
| ledger-charts | none | — | reads archive day files + VPS paper events; no network |
| ledger-archive | `/opt/ledger-gateway/.env` | gateway admin URL + DATABENTO_API_KEY | needs the Databento key; DB use is one SELECT on bars |

Neither least-privilege unit sees DATABENTO_API_KEY or the admin DATABASE_URL. Roles/grants: `sql/002_ops_roles.sql`; passwords are
generated by `mkroles.py` (never printed or committed); `mkroles.py --rotate` reissues them. The archive still uses the gateway env
because it is the only job that needs the Databento key; giving it its own role would split one file into two copies of the same key.

## Side effects of install.sh (outside /opt/ledger-ops)
* **DDL on PROD Supabase**: `sql/001_ops_monitoring.sql` (tables, view, RLS) and `sql/002_ops_roles.sql` (login roles, grants, RLS policies — including SELECT-only policies `ops_ro_select` on the gateway tables `live_market_bars_1m` / `live_market_ticks` scoped to the two ops roles). Idempotent.
* **journald restart**: writes `/etc/systemd/journald.conf.d/ledger.conf` and restarts `systemd-journald` only when that file changed.
* **swap + /etc/fstab**: only if the host has *no* swap, creates `/swapfile-ledger` (1 GB) and appends it to `/etc/fstab` (skipped here: 2.3 GB swap exists).
* `/etc/ledger-ops/*.env`, `/etc/logrotate.d/ledger-ops`, `/etc/tmpfiles.d/ledger-ops.conf`, system user `ledgerops`.

## Connectivity / heartbeats
The box can only reach 443 and the VPS can't reach the box, so they meet in Supabase:
* box → `box/box_heartbeat.py` (loop via `box/run_heartbeat.sh`, every 30s; card fetch every 60s) upserts `ops_heartbeats(source='box')` over REST
  with the service_role key: watcher pid alive, watcher `status.json` mtime + heartbeat (rewritten ~every 12s; alerted as `watcher_status_stale` > 3 min — watcher.log is event-driven, went quiet 3–6 min in normal running and flapped, so it is reported but not alerted), paper-trend pid / state mtime / last event, desk card fetch status.
* VPS → `watchdog.py` reads that row over `DATABASE_URL`, plus the gateway tables, the desk card API (every 5 min) and the host.

## Alerts (channel: Supabase `ops_alerts`, no email / chat)
One row per incident (partial unique index on `alert_key where state='open'`); while firing only `last_seen_at` updates; when it
clears the row is set `state='resolved'` + `resolved_at` (the recovery notice). Also appended to `/var/log/ledger-ops/alerts.log`.

Poll cheaply:
```
curl -s "https://<ref>.supabase.co/rest/v1/ops_alerts_open?select=*" -H "apikey: $SUPABASE_SERVICE_ROLE_KEY" -H "Authorization: Bearer $SUPABASE_SERVICE_ROLE_KEY"   # [] = all clear
curl -s ".../rest/v1/ops_heartbeats?source=eq.vps_watchdog&select=updated_at,payload"     # watchdog's own liveness + firing list
ssh lg cat /var/lib/ledger-watchdog/status.json
```
Tables have RLS on and no policies (anon/authenticated revoked).

Test alert: `touch /var/lib/ledger-watchdog/TEST_ALERT` → `test_alert` opens on the next run; `rm` it → resolves.

## Install
```
tar czf - -C ops vps charts | ssh lg 'mkdir -p /root/ld-ops-src && tar xzf - -C /root/ld-ops-src && /root/ld-ops-src/vps/install.sh'
# box side
cp ops/vps/box/* /workspace/ops-heartbeat/ && nohup /workspace/ops-heartbeat/run_heartbeat.sh >/dev/null 2>&1 &
```
